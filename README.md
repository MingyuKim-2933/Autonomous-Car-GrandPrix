# Autonomous Car GrandPrix

2021년 동국대학교 자율사물 경진대회(자율주행 자동차 경진 그랑프리) **우수상** 수상 코드입니다.

자이트론 Xycar A2(실제 자동차의 1/10 크기)로 교내 주행 트랙을 달리며 차선 주행, 신호등, 정지선, 장애물, 갈림길, 정지 차량 회피 미션을 수행하고 완주하는 대회입니다.

## 미션과 동작 흐름

```
카메라(640×480) ──► 차선 인식 ──► 조향각 계산 ──┐
       │                                        ├──► xycar_motor (조향, 속도)
       └──► HSV 색 인식(정지선, 신호등)          │
라이다 ─────► 전방 장애물 검사 ─────────────────┘
```

노란 정지선을 만날 때마다 다음 단계로 넘어가는 4단계 상태 머신으로 미션을 진행합니다.

| 단계 | 미션 | 동작 |
|---|---|---|
| 1 | 신호등 + 장애물 | 정지선에서 멈춘 뒤 빨간불이면 대기, 초록불이면 출발 |
| 2 | 신호등 + 장애물 | 1단계와 같고, 라이다 검사 각도를 넓혀 장애물을 더 넓게 확인 |
| 3 | 신호등 | 정지선 앞 신호 대기 후 출발 |
| 4 | 갈림길 + 정지 차량 | 정지선에서 멈춘 뒤 전방 차량을 라이다로 확인해 후진, 우회 |

## 구현 상세

### 차선 인식
- 그레이 변환 → 5×5 가우시안 블러 → Canny(60, 70)로 엣지 추출
- 차량 바로 앞의 띠 모양 ROI에서만 `HoughLinesP`로 선분을 찾고, 기울기로 왼쪽과 오른쪽 차선을 나눔
- 두 차선의 중앙과 화면 중앙의 차이를 조향각으로 사용

### 색 인식 (HSV)
- 노란 정지선, 빨간불, 초록불의 HSV 범위를 따로 정의
- ROI를 용도별로 나눠 오인식을 줄임
  - 아래쪽: 노란 정지선
  - 위쪽 가운데: 3구 신호등
  - 위쪽 왼쪽, 오른쪽: 갈림길 신호등
- 검출된 행 수가 임계값을 넘을 때만 반응 (빨강, 초록 10행 이상, 노랑 20행 이상)

### 장애물 (라이다)
- 전방 62°~117° 구간에서 0.3m 이내 점이 3개를 넘으면 정지
- 2단계에서는 검사 구간을 130°까지 넓힘

### 갈림길
- 왼쪽과 오른쪽 신호등 ROI의 초록색 검출량을 비교해 더 많이 켜진 쪽으로 회전

## 파일 구성

| 파일 | 설명 |
|---|---|
| `autodrive.py` | 자율주행 노드 (차선, 색 인식, 라이다, 미션 상태 머신) |
| `autodrive.launch` | 모터, 라이다, USB 카메라(640×480, 노출 고정), 자율주행 노드 실행 |
| `ROS_설치.pdf`, `Ubuntu_18.04 설치.pdf` 등 | 개발 환경 구축 자료 |

## 실행

Xycar A2의 ROS 패키지(`xycar_motor`, `xycar_lidar`, `usb_cam`)가 설치된 환경에서 실행합니다.

```bash
roslaunch auto_drive autodrive.launch
```

## 기술 스택

Python, ROS, OpenCV, NVIDIA Jetson TX2, Xycar A2, 라이다

## 배운 점

- Jetson TX2에서 실시간으로 돌리기 위해 ROI를 좁게 잡고 연산을 줄이는 최적화가 중요했습니다.
- 조명이 바뀌면 색 인식이 흔들려서, HSV 임계값을 현장에서 다시 맞추며 오류를 줄였습니다.
